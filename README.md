## Featured Build: PrepSetu

PrepSetu is my active full-stack product: an AI placement coach for Indian engineering students. It helps students practice realistic technical, HR, and coding interviews, then gives structured feedback and a personalised improvement plan.

| Link | Details |
| --- | --- |
| Live website | <https://placement-prep-ai-one.vercel.app> |
| Repository | <https://github.com/anant-x/placement-prep-ai> |
| Mock interview | <https://placement-prep-ai-one.vercel.app/interview/setup> |
| Sample report | <https://placement-prep-ai-one.vercel.app/sample-report> |
| College pilots | <https://placement-prep-ai-one.vercel.app/colleges> |

What it includes:

- AI interview flow with role, branch, round, difficulty, company type, and focus-topic setup.
- Curated DSA, CS fundamentals, and HR question bank with AI scoring.
- Student accounts, interview history, and session summaries.
- College readiness dashboards and institution onboarding.
- Stripe billing, admin review tools, and production deployment on Vercel.
- Short-form marketing video workflows using HyperFrames and Remotion.
